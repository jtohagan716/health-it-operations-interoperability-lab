SMART / OAuth Authorization | v Bearer Access Token | v Granted user/Resource.rs Scope | v Authenticated EHR User Context provider01 | v EHR ACL / Policy Evaluation / \ / \ PERMIT DENY | | HTTP 200 HTTP 403

Finding

The OAuth client successfully authenticated and received SMART user-context scopes for Patient, Encounter, Practitioner, and Organization resources. Patient and Encounter operations were permitted. Practitioner and Organization operations were denied with HTTP 403 despite the corresponding SMART scopes being present in the access token. The observed behavior demonstrates that possession of a SMART scope does not, by itself, guarantee access to the requested EHR resource. Resource access is also subject to authorization policy associated with the authenticated EHR user context.
